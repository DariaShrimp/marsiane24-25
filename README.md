# МарсИЭТ — ППО ИТ 2024/25

Проект для заключительного этапа Московской предпрофессиональной олимпиады школьников.  
Цель: восстановить карту Марса, разместить базовые станции и обеспечить связь между модулями «Эл-12» и «Фар-3».

## Технологии
- Python, Flask, Jinja2
- SQLite
- HTML/CSS/JS

## Запуск
1. Установите зависимости: pip install -r requirements.txt
2. Запустите: python main.py
3. Перейдите в браузере: http://127.0.0.1:8080
